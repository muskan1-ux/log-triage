# Log Triage

A Kafka consumer that uses an LLM (via LangChain4j) to automatically triage application
error logs into severity, root cause, and a suggested action - protected by a
Resilience4j circuit breaker and retry so a struggling LLM provider degrades gracefully
instead of taking the pipeline down with it.

**Stack:** Java 17 - Spring Boot 3.5 - Apache Kafka - LangChain4j - Resilience4j.

## How it works

1. A `LogEvent` (service, level, message, stack trace) arrives on the `logs.raw` Kafka topic.
2. `LogConsumer` picks it up and calls `LogTriageService`, a LangChain4j AI service that
   asks an LLM to return a structured `TriageResult` (severity / root cause / suggested action).
3. That call is wrapped in `@Retry` (handles brief blips) and `@CircuitBreaker` (stops
   hammering a struggling provider and falls back to a safe "route to on-call" result instead).
4. Malformed/poison messages that fail deserialization are retried a few times, then
   published to `logs.raw.DLT` by Spring Kafka's `DeadLetterPublishingRecoverer`.

## Why it's structured this way

- **One package, no sub-folders.** Small enough that a flat structure is more readable
  than the usual `config/consumer/service/model` split - reviewers can see the whole
  pipeline in six files.
- **Resilience4j on a plain method, not the LangChain4j proxy.** `LogTriageService` is a
  dynamic proxy generated by LangChain4j's `AiServices` at runtime, so `@CircuitBreaker`
  and `@Retry` are placed on `LogConsumer.triage(...)` instead - that's the method Spring's
  AOP proxy can actually intercept.

## Running locally

You need a Kafka broker reachable at `localhost:9092` (e.g. `docker run -p 9092:9092 apache/kafka:3.8.0`).

```bash
export OPENAI_API_KEY=sk-...   # optional - falls back to a safe default triage if unset/invalid
mvn spring-boot:run
```

Publish a test message:

```bash
echo '{"eventId":"evt-1","service":"checkout","level":"ERROR","message":"Connection timed out","stackTrace":"java.net.SocketTimeoutException"}' | \
  kafka-console-producer.sh --broker-list localhost:9092 --topic logs.raw
```

Watch the console log for the triage result.
